# 获客与话术

> 服务再好，没人知道就等于零。这份文档解决「第一批客户从哪来」。

---

## 一、渠道优先级：按「信任距离」排，不是按平台流量排

这个产品有个特性必须先认清：**没有人会主动想要一次代码安全体检**。
需求是被事件激发的（被拖库、被客户要求、被招标卡住），不是被广告激发的。
所以渠道选择的第一性原理是**信任距离**——谁已经认识你、已经信你，就从谁开始。
平台是放大器，不是启动器；冷启动阶段指望平台开单，等于把最难的信任问题外包给算法。

| 优先级 | 渠道 | 信任距离 | 为什么排这里 |
|---|---|---|---|
| 0 | **你自己的学员池** | 已有信任 | 买过你课的人 = 正在做 AI 应用的人 = 这套规则库的精准客户，获客成本为零 |
| 1 | **直接人脉** | 一层转介 | 前 3 单不该指望陌生人。要的是案例授权和评价，这两样只有熟人愿意给 |
| 2 | **技术内容渠道**（知乎 / 掘金 / 小红书，三选一） | 靠专业度建立 | 内容是这个产品唯一的教育手段，"事故故事"比"服务介绍"有效十倍 |
| 3 | **需求平台**（猪八戒 / 猿急送 / Upwork） | 需求已存在 | 这里的人已经在找"代码审计"，你不用教育市场，只需要报价 |
| 4 | **闲鱼** | 最远 | 随手挂，不是主战场。价值在验证价格和攒评价，不在成交量 |
| 5 | 云厂商服务市场 | 平台背书 | 需要企业资质，是 6 个月之后的事 |

### 第 0 位：你自己的学员池（最大杠杆，别浪费）

如果你在做 AI 应用方向的课程（Coze RAG、Agent 工具工作流 MCP、评估部署安全、Python 实战），
那么买这些课的人，正好就是 CodeAudit 里 AI 专项规则（提示注入、模型输出被直接执行、
Agent 工具越权、MCP 明文密钥、大模型 Key 泄露到前端）覆盖的那批应用。

这意味着三件事：**他们已经信你；他们做的东西正好有这些风险；你课程里的安全章节
已经替你把安全意识铺垫好了。** 这是任何平台都给不了的起点。

别在群里硬推服务。正确开口方式是用真实发现说话：

> 最近写了个代码体检工具，拿几个学员的项目试了下，发现 3 个里有 2 个
> 把大模型 Key 直接写在了前端页面里——任何访客打开浏览器就能看到，
> 等于把账户余额公开挂出去。有意思的是这跟代码写得好不好没关系，
> 是 AI 帮忙写代码时的通病。想自查的私我，前几个免费看。

这条消息同时完成了四件事：展示专业能力、给出真实案例、提供低成本入口、不推销。

### 第 1 位：直接人脉（前 3 单从这里出）

前 3 单的目标不是赚钱，是拿到**案例授权**和**真实评价**——这两样只能从熟人身上拿。
而且你要的不是你认识的人，是**你认识的人认识的老板**。

发给 5 个前同事/朋友：

> 我在做一个代码安全体检的服务，专门查密钥泄露、SQL 注入这类上线后才会炸的问题。
> 前 3 个客户我半价做，唯一条件是允许我脱敏之后把项目写成案例。
> 你身边有没有刚上线小程序或网站的老板？帮我引荐一下。

要点：把"要什么"（案例授权）说清楚，比说"我给你打折"更容易被答应——
因为你是在请他帮忙，不是在求他消费。帮忙是社交，消费是压力。

### 第 2 位：内容渠道三选一，不要铺开

- **知乎**：搜「代码审计多少钱」「等保怎么过」「被拖库了怎么办」的人，采购意向最强，
  适合发"决策参考"型内容；
- **掘金 / CSDN**：技术负责人和开发者聚集，适合发技术细节型内容，积累专业信誉；
- **小红书**：中小企业主和个体经营者多，适合发"事故故事"型内容，情绪驱动转发。

选一个主攻，每周 2 条，坚持 8 周再评估。三个都做等于三个都做不好。

### 第 3 位：需求平台（这里的人已经在找你了）

猪八戒、猿急送、一品威客 搜「代码审计 / 安全检测 / 漏洞扫描」，有真实需求帖就直接投标。
海外方向看 Upwork，上面已经有人在找 *Security Check for Vibe Application*——
AI 生成的应用要做安全检查，这正是你的定位，客单价还比国内高一个量级。

### 第 4 位：闲鱼（随手挂，但注意风控）

闲鱼的价值是验证价格和攒评价，不是成交量。挂的时候有两个坑：

- **别用敏感词**：不要写「渗透测试」「漏洞利用」「黑客」，容易被风控下架甚至封号。
  用「代码安全体检」「源代码检查」「上线前自查」这类表述。
- **别只等搜索**：搜「小程序开发」「网站开发」的在售/求购帖，主动私信提供增值服务，
  成交率远高于等客人搜到你的商品。

## 二、闲鱼冷启动（最快验证）

**商品标题**（关键词要能被搜到）

```
代码安全检测 漏洞扫描 源码审计 密钥泄露检查 支持AI应用
```

**详情页结构**（照抄改数字即可）

```
【服务内容】
对你的项目源码做一次安全体检，找出可能导致数据泄露、被入侵、
被薅算力的代码问题，输出一份开发能直接照着改的中文报告。

【检出范围】
· 密钥/口令/云凭据硬编码
· SQL 注入、命令执行、路径穿越、SSRF 等注入类缺陷
· 不安全反序列化、弱加密算法
· 越权与鉴权缺失
· AI 应用专项：Prompt 注入面、模型输出被直接执行、
  Agent 工具越权、大模型 Key 泄露到前端

【交付物】
HTML 报告（双击可看）+ Markdown（开发用）+ JSON（可接 CI）
每条问题都有：文件行号 / 风险说明 / 修复建议 / 验证方法

【价格】
体验款 ¥299（单个仓库或模块，24 小时出报告，不含人工答疑）
标准款 ¥1280（20 万行以内，3 个工作日，含人工复核 + 30 分钟答疑）
专业款 ¥2980（100 万行以内，含复现验证、复测与英文摘要）
前三个客户有破冰折扣，详情问客服。

【说明】
仅接受自有或已获授权的系统，需签署检测授权书。
报告中的密钥已打码，可安全转发。
```

**上架后要做的事**：体验款本身就是引流 SKU，不用再另做一个。
用它攒 3–5 条真实评价，再主推标准款。评价里务必出现「报告很详细」「知道怎么改了」
这类词——这是转化率最高的素材，比任何话术都有效。

## 三、内容选题（10 个可直接用）

标题公式：**具体数字 + 反常识结论 + 与我有关**

1. 我扫了 12 个开源 AI 项目，7 个把大模型 Key 写在了前端
2. 你的代码里可能藏着一个能刷爆账户的 Key，三步自查
3. AI 客服上线前必须检查的 5 件事，第 3 条最容易出事
4. 为什么给客户交安全报告，不能直接跑一遍扫描器就发
5. 一份代码体检报告长什么样？我把自己的项目扒了一遍
6. 用 AI 写代码半年，我总结了 6 类它最容易写错的安全模式
7. 客户要求提供安全证明，小团队怎么低成本应付
8. 提示注入不是概念，我复现了 3 种能骗过客服机器人的输入
9. 数据库口令写在配置文件里，到底有多危险？算一笔账
10. 安全体检 vs 渗透测试：中小企业到底该先做哪个

**发布节奏**：每周 2 条（1 条技术、1 条故事）。技术条建立专业度，故事条带来私信。

## 四、话术模板

### 场景 1：客户来问价，还没说需求

> 你好，先了解几个信息好给你准确的方案：
> 1. 代码大概多少行、什么语言？
> 2. 有没有用到 AI 功能（大模型接口、Agent、知识库）？
> 3. 是想上线前自查，还是客户/招标要求？
>
> 如果方便，发一份项目目录结构给我，我先免费帮你看哪些模块最值得优先检测。

要点：先问再报，不要一上来甩价格。免费评估是最有效的钩子。

### 场景 2：客户说「太贵了」

> 理解。先确认一下，你说的贵是跟什么比？
> 如果是对比免费扫描工具，那差的是人工——工具给你 200 条告警，你得自己判断哪些是真的；
> 我们是把误报剔掉、按优先级排好、每条都写清楚怎么改，再开会给你讲一遍。
>
> 如果确实是预算问题，先上 299 的体验款，就看一份报告长什么样，觉得有用再谈完整版。
> 也可以降范围不降单价：你有三个仓库就先扫最核心的那个，按单仓库算。
>
> 出问题最多的通常是接口层和配置管理，这两块扫一遍性价比最高。
> 没问题，你花小钱买个放心；有问题，那就是省下了未来可能的损失。

要点：先反问「跟什么比」，把客户的比较锚点从价格拉到价值。
不降价、只降范围；低价 SKU 只给报告不给人工讲解，想听讲解就必须升级档位。

### 场景 3：客户说「我们自己有扫描工具」

> 那挺好的，基础扫描你们已经覆盖了。
> 我们能补两块：一是误报剔除和优先级排序，工具给的告警列表开发通常看不完；
> 二是 AI 应用这块——Prompt 注入面、模型输出被拿去执行、Agent 工具权限，
> 多数通用工具目前不检测。
>
> 你也可以先把工具的输出发我，我免费帮你判断哪些是真问题，你再决定要不要做完整的。

要点：不否定客户的现状，找一个它覆盖不到的缺口切进去。

### 场景 4：客户说「先免费做一次吧」

> 我可以先免费做一次范围评估——看目录结构、看技术栈、指出哪几类风险最可能出现在你这个项目里，
> 这个没问题。
> 但完整的检测和报告涉及人工复核和交付，这部分需要走正式流程。
> 我建议先上 299 的体验款，一顿饭钱，你能真实看到交付质量，再决定要不要继续。
> 体验款只给报告、不含讲解，想听我逐条过一遍高危项，那就升级到标准款。

要点：免费的边界是「判断」，付费的价值是「交付」。这个界限一定要清晰。

## 五、让客户复购和转介绍

1. **复测是天然的第二单**。交付时就在会议纪要里写明客户承诺的修复时间，到期主动跟进。
2. **订阅制**：迭代快的团队推季度订阅（每月扫一次 + 随时答疑），把一次性收入变成可持续收入。
3. **转介绍**：交付后主动说一句「如果身边有团队要做上线前自查，可以推给我，老客户介绍的有折扣」。成交后给介绍人返 10% 或送一次复测。
4. **沉淀案例**：每做完一单，脱敏后写成一篇案例文（问题类型 + 修复前后对比）。这是最强的获客素材。

## 六、第一周的执行清单

按信任距离从近到远，做完一个再做下一个。

**第 1–2 天：把弹药准备好**

- [ ] 本机跑通 `python -m codeaudit demo`，把生成的 HTML 报告打开看一遍，自己先看懂
- [ ] 拿自己手头一个真实项目扫一遍，找出 5 个真实问题——这是你的第一个案例素材
- [ ] 用 `landing/index.html` 改出落地页，替换联系方式（`your-wechat-id` / `you@example.com`）

**第 3–4 天：从最近的地方开第一枪**

- [ ] 在学员群 / 老客户群里发那条「用真实发现说话」的消息（见第一章第 0 位），先摸底有没有人接话
- [ ] 给 5 个前同事 / 朋友发人脉话术，要的是「引荐」，不是「消费」
- [ ] 本周目标只有一个：谈成 1 个免费或半价的首单，条件是拿到案例授权

**第 5–7 天：把外部入口搭起来**

- [ ] 闲鱼上架 2 个 SKU：¥299 体验款 + ¥1,280 标准款（注意避开敏感词，见第一章第 4 位）
- [ ] 内容渠道三选一，发第一条（从下面 10 个选题里挑）
- [ ] 去猪八戒 / 猿急送搜一次「代码审计」，看看真实需求帖长什么样、别人都在报什么价
